# RBO Accounting — WordPress site

Private working copy of [rboaccounting.ae](https://www.rboaccounting.ae) (SEO + content project).

## Important

- `wp-config.php` and `wp-config-local.php` are **not** in git (secrets).
- Use `wp-config.example.php` as a template.
- Database dumps and WPvivid backups are gitignored.
- Deploy to cPanel: see `DEPLOY-TO-CPANEL/HOW-TO-MAKE-LIVE-ON-CPANEL.md`.

## Local

```powershell
.\start-local.ps1
```
